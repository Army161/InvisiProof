# Requester Guide

This guide covers everything you need to do as the person creating a Proof Request.

## Creating a request

1. Tap the **Requests** tab at the bottom of the screen
2. Tap **Create Request**
3. Fill in the **Purpose** — a short description of what you are asking for (this is shown to the respondent)
4. Add **Instructions** if needed — specific guidance for what the respondent should submit
5. Tap **Create**

InvisiProof generates a unique request code and a shareable link.

## Sharing the request

Share the code or link with the person you want to submit evidence. You can:

- Copy the link and send it via any messaging app
- Share the code verbally or in writing

The respondent does not need an InvisiProof account to submit evidence.

## Monitoring the request

Open the **Requests** tab to see the status of your requests:

- **Pending** — Waiting for the respondent to submit
- **Completed** — The respondent submitted and the assessment is ready
- **Expired** — The request was not completed before it expired
- **Cancelled** — You cancelled the request

When a request is completed, tap it to view the risk assessment result.

## Cancelling a request

To cancel a pending request, open it and tap **Cancel Request**. Cancelled requests cannot be reopened. The respondent's link will no longer work.

## What you can see

You receive the risk assessment result (risk level, score, summary, warning indicators, recommended actions). You do not automatically receive the raw evidence submitted by the respondent.

See [Privacy Boundaries](/proof-requests/privacy-boundaries) for details on what requesters can and cannot access.
