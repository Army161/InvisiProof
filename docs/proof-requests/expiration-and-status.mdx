# Expiration and Status

Every Proof Request has a status that tells you where it is in the workflow.

## Status definitions

### Pending

The request has been created and shared, but the respondent has not yet submitted evidence. The link is active and the respondent can still submit.

### Completed

The respondent submitted evidence and the assessment is ready. You can view the risk assessment result in your Requests tab.

### Expired

The request was not completed before its expiration time. The respondent's link no longer works. Expired requests cannot be reopened.

### Cancelled

You cancelled the request before it was completed. The respondent's link no longer works. Cancelled requests cannot be reopened.

## Expiration

Proof Requests expire after a set period if not completed. The expiration time is shown when you create the request and in the request detail view.

When a request expires:
- The respondent's link stops working
- The request status changes to **Expired**
- No assessment is generated

## What happens to submitted evidence after completion

After a request is completed, the submitted evidence remains in private storage. The respondent can delete their submission at any time. See [Data Retention](/privacy/data-retention) for details on how long data is kept.
