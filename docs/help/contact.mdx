# Contact

## Support

For general questions, account issues, billing problems, and feature requests:

**Email:** support@invisiproof.com

**Response time:** 1–2 business days

**Website:** [www.invisiproof.com](https://www.invisiproof.com)

### What to include in a support request

To help us resolve your issue quickly, include:

- **Your account email address**
- **Device and platform** (e.g. Samsung Galaxy S23, Android 14 / Chrome on Windows 11)
- **App version** (found in Profile → About)
- **Description of the issue** — what you were trying to do, what happened, and what you expected to happen
- **Steps to reproduce** — if the issue is repeatable, list the steps
- **Screenshots** — if applicable. Do not include screenshots with sensitive personal information (passwords, financial details, private messages)
- **Error messages** — copy the exact text of any error messages shown

## Security

For security vulnerability reports:

**Email:** security@invisiproof.com

**Response time:** Within 48 hours for acknowledgment

<Warning>
Do NOT report security vulnerabilities through the general support email or as public GitHub issues. Use security@invisiproof.com only.
</Warning>

See [Security Reporting](/privacy/security-reporting) for full details on scope, response timelines, and responsible disclosure policy.

## Legal

For legal inquiries, data subject requests (GDPR/CCPA), and licensing:

**Email:** legal@invisiproof.com

## Documentation

Full documentation is available at [docs.invisiproof.com](https://docs.invisiproof.com).

If you find an error or gap in the documentation, email support@invisiproof.com with the subject line "Docs feedback".
