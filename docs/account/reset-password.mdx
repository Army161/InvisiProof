# Reset Password

If you forgot your password or want to change it, follow these steps.

## Request a password reset

1. Open InvisiProof
2. Tap **Sign In**
3. Tap **Forgot Password**
4. Enter your email address
5. Tap **Send Reset Link**

You will receive an email with a password reset link. Check your spam folder if you do not see it within a few minutes.

## Set a new password

1. Open the reset link from your email
2. Enter your new password
3. Confirm the new password
4. Tap **Reset Password**

You are now signed in with your new password.

## Password requirements

- Minimum 8 characters
- We recommend using a unique password not used on other services

## If you signed up with Google or Apple

Password reset only applies to email/password accounts. If you signed up with Google or Apple, you do not have an InvisiProof password — sign in using the same method you used to create your account.
