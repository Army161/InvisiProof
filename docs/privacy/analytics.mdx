# Analytics

InvisiProof collects limited analytics data to understand how the app is used and to improve the product. This page explains exactly what is and is not collected.

## What InvisiProof collects

- **App events**: screen views, feature usage (e.g., "scan started", "proof request created"), button taps
- **Error events**: crashes and errors to help diagnose and fix problems
- **Session data**: session start/end, app version, device type (not device ID)
- **Subscription events**: plan changes, paywall views (no payment details)

## What InvisiProof does not collect

- **Submitted content**: images, text, URLs, or messages you submit for analysis are never included in analytics
- **Assessment results**: the content of risk assessments is not tracked
- **Proof Request content**: evidence submitted through Proof Requests is not tracked
- **Message content**: any text you paste or type is not included in analytics events

## Analytics providers

InvisiProof uses analytics infrastructure to collect and process usage data. Analytics data is not sold to third parties.

## Opting out

You can review your analytics preferences in **Profile → Privacy**. Opting out stops event collection for your account.

## Analytics and privacy

Analytics events are designed to be content-free. An event like "scan started" tells us a scan was initiated — it does not include what was scanned. This design is intentional and is part of InvisiProof's privacy-first approach.
