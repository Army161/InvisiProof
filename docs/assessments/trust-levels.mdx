# Trust Levels

Every InvisiProof assessment carries a trust level that describes how the analysis was produced — not how risky the content is. Trust levels and risk levels are independent.

## The two trust levels

<CardGroup cols={2}>
  <Card title="Server Verified" icon="server">
    The assessment was produced by InvisiProof's trusted server infrastructure. Analysis ran through InvisiProof's managed AI pipeline after authenticated server-side processing.
  </Card>
  <Card title="Device Generated" icon="mobile">
    The assessment was produced through a provider you configured (BYOK). Analysis ran through your own API key and provider account, not InvisiProof's server infrastructure.
  </Card>
</CardGroup>

## What trust levels describe

Trust levels describe the **analysis path** — where the AI processing happened and who controls the AI provider account used.

| Trust Level | Analysis ran through | API key used |
|-------------|---------------------|--------------|
| Server Verified | InvisiProof's server infrastructure | InvisiProof's managed key |
| Device Generated | User-configured BYOK provider | Your own API key |

## What trust levels do NOT describe

Trust levels do **not** indicate:
- Whether the risk assessment is accurate
- Whether the content is safe or dangerous
- Whether the AI model used is better or worse
- Whether you should trust the result more or less

<Note>
A Device Generated assessment is not less reliable than a Server Verified one. The trust level simply tells you which analysis path was used. Both paths use capable AI models and the same structured analysis prompt.
</Note>

## When trust levels are shown

Trust levels are shown on every completed assessment result. They appear alongside the risk level and risk score in the assessment detail view.

## Trust levels and Proof Requests

For [Proof Requests](/proof-requests/overview), the trust level reflects how the respondent's evidence was analyzed:

- If the respondent submitted evidence through InvisiProof's standard flow, the result is **Server Verified**
- If the respondent used a BYOK-configured account, the result is **Device Generated**

The requester sees the trust level as part of the result, giving them context about how the analysis was produced.

## Relationship to BYOK

The Device Generated trust level is assigned when you have configured a [BYOK (Bring Your Own Key)](/privacy/byok) provider and that key was used for the analysis. This gives you full control over which AI provider processes your content, at the cost of the Server Verified label.

If you want Server Verified assessments, remove your BYOK key from the app settings and assessments will route through InvisiProof's server infrastructure.
