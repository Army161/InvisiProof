# Changelog

## v1.0.0 — January 2025

**Initial release**

InvisiProof launches on Android and web.

### Features

**Direct Assessments**
- Analyze Image — upload a screenshot, photo, or document image for visual signal analysis
- Analyze Text — paste a message, email, or conversation for linguistic pattern analysis
- Analyze URL — submit a link for structural risk analysis without visiting it from your device
- Risk levels: Low, Medium, High, Critical (scores 0–100)
- Warning indicators with category, description, and severity
- Recommended actions tailored to risk level
- Assessment history with plan-based retention

**Proof Requests**
- Two-party workflow: requester creates a challenge, respondent submits evidence privately
- 6-digit code sharing
- Expiry options: 24 hours, 48 hours, 7 days
- Statuses: Pending, Submitted, Analyzing, Completed, Expired
- Privacy boundary enforced at database level (RLS): requester sees result only, never raw evidence

**BYOK (Bring Your Own Key)**
- Supported providers: OpenAI, Anthropic, Google Gemini
- API keys stored encrypted in Supabase
- Device Generated trust level for BYOK assessments
- Server Verified trust level for InvisiProof-managed assessments

**Subscription tiers**
- Free: 2 assessments/month, 7-day history
- Plus: $14.99/month or $99.99/year — 25 assessments/month, 90-day history, BYOK
- Pro: $34.99/month or $249.99/year — 150 assessments/month, unlimited history, priority analysis
- Max: $79.99/month or $599.99/year — unlimited assessments, unlimited history, all features
- Android subscriptions via Google Play / RevenueCat

**Privacy and security**
- Supabase Row Level Security on all user data tables
- Private storage bucket for images (no public URLs)
- Analytics via PostHog (no content tracked, opt-out available)
- Account deletion with full data removal
- GDPR/CCPA data subject request support

**Platforms**
- Android (Google Play)
- Web (invisiproof.com)
